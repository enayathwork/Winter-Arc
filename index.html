Sync

  1. Create a blank sheet at sheets.google.com and name it "Winter Arc".
  2. Go to Extensions → Apps Script, delete the sample code, and paste the script below.
  3. Click Deploy → New deployment, gear icon → Web app.
  4. Set Execute as: Me and Who has access: Anyone, then Deploy and approve permissions (Advanced → Go to project if warned).
  5. Copy the Web app URL (ends in /exec), paste it in the field above, tap Save settings, then Test sync.

      

      

      
After editing the script later, use Deploy → Manage deployments → Edit → New version. This hosted page may block outside requests, so sync can fail here; host the file yourself (e.g. Netlify Drop) for live sync.
